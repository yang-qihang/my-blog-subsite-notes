# Vim's Basic Syntax

## Differents Modes in Vim

- Normal mode

- Visual mode

- Insert mode

- **Command-line mode**

    - `:`

    - `/`

    - `?`

## 3 Types of Editing Commands

1. Operator + Motion

     e.g. `v` + `tj`

2. Operator + Text Object
   
     More specifically, there are two syntaxs for text objects:
   
       1. Inner(`i`)

       2. Around(`a`)

     e.g. `v` + `iw`

3. Visual selection + Operator

     e.g. `v` + `iw` + `d`
